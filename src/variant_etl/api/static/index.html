Variant ETL

Genomic variant pipeline and analytics
checking API reference Source

From a raw variant file to clean, queryable data.

Provide a VCF file (a list of differences in DNA) and a reference genome. The service validates every line, rewrites each change into one standard form, stores the result in a database and reports the statistics.

Process

How it works

What happens behind the button, in four steps.

01UploadThe browser sends the files directly to object storage (S3). The API never handles the file bytes.
02SplitOne worker cuts the file into chunks of 100,000 records.
03ProcessWorkers handle chunks in parallel: reject bad lines, normalize the rest, bulk-load into PostgreSQL.
04Finalize and queryTotals are computed; the API serves statistics and searchable variants.
