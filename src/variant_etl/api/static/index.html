Turn a raw genome variant file into clean, queryable data.

Upload a VCF file (a list of DNA differences) and a reference genome. The service checks every line, fixes how each change is written, stores the result in a database, and shows you the statistics.

How it works

What happens behind the button, in four steps.

1UploadYour browser sends the files straight to object storage (S3). The API never handles the bytes.
2SplitOne worker cuts the big file into chunks of 100,000 records.
3ProcessMany workers handle chunks in parallel: reject bad lines, normalize the rest, bulk-load into PostgreSQL.
4Finalize & queryTotals are computed and the API serves statistics and searchable variants.

Use the built-in sample (3,000 records with some deliberate errors), or drop your own files.
